─────────────────────────────────────────────────────────────────

    → Cliquez sur "Developers" puis "API keys"
    → Copiez vos clés TEST (pk_test_... et sk_test_...)

2️⃣  CONFIGURER .ENV.LOCAL
    → nano /root/xcannes-dex/Xcannes-/.env.local
    → Remplacez les lignes :
      NEXT_PUBLIC_STRIPE_PK=pk_test_51Abc...
      STRIPE_SECRET_KEY=***REMOVED***
    → Sauvegardez : CTRL+O, Enter, CTRL+X

3️⃣  REDÉMARRER LE SERVEUR
    → cd /root/xcannes-dex/Xcannes-
    → pm2 restart xcannes-frontend --update-env

4️⃣  TESTER L'INSTALLATION
    → cd /root/xcannes-dex/Xcannes-
    → ./test-stripe.sh
    → Résultat attendu : "✅ API fonctionne (mode TEST)"

5️⃣  TESTER UN PAIEMENT
    → Ouvrez http://localhost:2500 dans votre navigateur
    → Cliquez sur "Buy with Card / Apple Pay"
    → Utilisez la carte de test : 4242 4242 4242 4242
      Date : 12/28
      CVV  : 123
      ZIP  : 12345
    → Validez le paiement
    → Vous serez redirigé vers /success

6️⃣  VÉRIFIER DANS STRIPE DASHBOARD
    → https://dashboard.stripe.com/test/payments
