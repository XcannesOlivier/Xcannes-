# XCANNES Frontend (Next.js)

## Démarrage rapide

- Installer : `npm install`
- Dev : `npm run dev` (par défaut sur `http://localhost:2500`)
- Build : `npm run build`
- Start : `npm run start`

## Configuration

- Exemple : `.env.local.example`
- Fichier local : `.env.local`
